3. Trois décisions à prendre

Décision 1 — Une seule entrée admin

/admin rend l'ancien AdminDashboard (qui tire AdminStats et DriversManager), /admin/dashboard rend la génération actuelle. Deux interfaces admin coexistent en production. Recommandation : /admin devient une redirection vers /admin/dashboard, et les trois fichiers partent avec.

Décision 2 — Permissions : import fantôme

La page importe ModernPermissionsManagement (64,8 ko) mais rend PermissionsManagementRedesigned (ligne 185). L'import est payé au build sans jamais s'afficher. Supprimer l'import et le fichier.

Décision 3 — Un composant admin dans l'espace client

ModernUsersManagement (63,8 ko) vit dans admin/ mais n'est utilisé que par client/ClientUsersManagement. Le déplacer dans components/shared/ — sinon il sera supprimé par erreur au prochain nettoyage admin.
