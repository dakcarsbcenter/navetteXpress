Protection du rôle admin

Le rôle admin n'est pas configurable ici : le code court-circuite la vérification et rend l'accès total avant de lire la table des permissions. Le retirer de l'interface ne le retire pas du code.

if (userRole === 'admin') {
  return true
}

Deux héritages à trancher

Le rôle client passe par un contournement. Le même code accorde l'accès aux réservations à tout customer sans consulter la table, avec le commentaire « comportement legacy ». Sa ligne dans cette matrice est donc décorative.

Quatre migrations se contredisent sur le rôle manager : manager-read-update-only, fix-manager-permissions, fix-manager-permissions-complete, fix-manager-delete-permissions. L'état réel dépend de l'ordre d'exécution.
